# 🎓 Tugas Individu - Mata Kuliah Bahasa Pemrograman 1
### 🏴‍☠️ Dunia One Piece - Web Fanpage

Repository ini berisi *source code* website statis bertema **Dunia One Piece**. Proyek ini dibuat sebagai **Tugas Individu** untuk mata kuliah Bahasa Pemrograman 1, yang berfokus pada implementasi dasar Semantic HTML, CSS Layouting, dan interaktivitas antarmuka menggunakan JavaScript.

## 🚀 Fitur Utama Aplikasi
* **Responsive Navbar:** Menu navigasi utama yang responsif dilengkapi *hamburger menu* untuk tampilan mobile.
* **Profile & Info Table:** Penjelasan singkat tentang sinopsis anime One Piece yang dilengkapi tabel informasi detail.
* **Character Cards (Kru Mugiwara):** Layout grid yang menampilkan profil anggota Bajak Laut Topi Jerami beserta nilai buruan (*bounty*) mereka.
* **Timeline Arc:** Daftar urutan cerita (Arc) utama dalam seri One Piece dari East Blue hingga Final Saga.
* **Fakta & Teori:** Kumpulan trivia dan teori menarik seputar misteri dunia One Piece.
* **Galeri Gambar:** Kumpulan momen ikonik dan visual karakter yang disusun rapi.
* **Interaktivitas UI:** Dilengkapi dengan efek pemuatan layar (*Loading Screen*) saat web pertama kali dibuka dan tombol *Back to Top* dinamis untuk navigasi cepat.

## 🛠️ Tech Stack & Assets
* **Frontend:** HTML5, CSS3, JavaScript (Native).
* **Fonts & Icons:** Google Fonts (Bangers & Poppins), Font Awesome (v6.0.0).
